# Названия игр в запросах пользователя

- `csso` / `CSSO` / `CS:SO` означает именно Counter-Strike: Source Offensive (локальный мод `csso`). Это самостоятельное обозначение, а не опечатка или сокращение CSS либо CS:GO.
- Если пользователь пишет `csso`, работай именно с CSSO: её ресурсами, настройками, интерфейсом и поведением. Не подменяй игру Counter-Strike: Source (CSS / CS:S), Counter-Strike: Global Offensive (CSGO / CS:GO) или CS2.
- Локальная CSSO находится в `C:/Program Files (x86)/Steam/steamapps/common/Counter-Strike Source/csso`. Название родительской папки `Counter-Strike Source` не меняет того, что запрос относится к CSSO.
- Сходство с другой игрой, общая база движка и имена существующих файлов `css_*` не дают основания менять указанную пользователем игру. Проверяй сведения по CSSO; если нужных данных нет, прямо сообщи об этом, не выдавая данные другой игры за CSSO.
