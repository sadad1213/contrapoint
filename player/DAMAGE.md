# Урон CSS

Падение, HE, шесть имеющихся огнестрельных оружий и нож используют общую
обработку урона. В LAN здоровье, броню, смерть и попадания считает хост.
Клиент передаёт направление выстрела, а не величину урона. Административный
`TakeDamage(int)` оставлен для `kill` и служебных проверок.

## Данные оригинала

`tools/source_import/import_css_damage.py` читает установленный stock CSS VPK:
29 оригинальных `weapon_*.ctx`, девять звуковых скриптов с 27 WAV, параметры
HE DSP 137–139 и хитбоксы четырёх T-моделей из сохранённых MDL v44.
Архивы игры не изменяются. Источники и SHA-256 записаны в
`assets/physics/css_damage/provenance.json`. Оружия, которых ещё нет в
инвентаре/сценах, этот импорт сам по себе не добавляет.

```powershell
python -m pip install ICECipher
python tools/source_import/import_css_damage.py
```

Альтернатива установке в Python: `pip install --target <directory> ICECipher`,
затем `--dependencies <directory>`. `import_css_damage_effects.py` запускается
в background Blender с существующим SourceIO: извлекает оригинальные текстуры
крови и искр, включая Subrect-области атласа. У каждого ассета есть provenance.

## Пули, броня, нож

Огнестрельный луч пересекает оригинальные bone-local OBB из MDL, привязанные
к текущему скелету Godot. Двигательный hull не подменяет хитбоксы головы,
живота, рук и ног. Ближайшая мировая коллизия закрывает игрока.

| Оружие | Базовый урон | WeaponArmorRatio | RangeModifier | Дальность, units |
| --- | ---: | ---: | ---: | ---: |
| AK47 | 36 | 1.55 | .98 | 8192 |
| M4A1 | 33 | 1.4 | .97 / .95 с глушителем | 8192 |
| USP | 34 / 30 с глушителем | 1 | .79 | 4096 |
| Deagle | 54 | 1.5 | .81 | 4096 |
| AWP | 115 | 1.95 | .99 | 8192 |
| Scout | 75 | 1.7 | .98 | 8192 |

Урон на дистанции: `damage * pow(RangeModifier, distance / 500)`, расстояние
в Source units. Голова ×4, живот ×1.25, ноги ×.75; грудь и руки ×1.
Кевлар защищает generic/грудь/живот/руки, голову — только со шлемом;
ноги и падение обходят броню.

Для защищённой области `healthDamage = damage * WeaponArmorRatio * .5`,
`armorDamage = (damage - healthDamage) * .5`. При нехватке брони избыток
переходит в здоровье. Броня целочисленная. **CCSPlayer отбрасывает дробную
часть HP каждого события перед базовым аккумулятором**: прежнее накопление
дробей между ударами здесь удалено.

Пробитие использует запас/дистанцию соответствующего патрона, коэффициенты
бетона, дерева, металла, земли, решётки, вентиляции, плитки и компьютера,
потери урона, уменьшение дальнейшей дальности и TraceToExit с шагом 24 units
до предела 128. Одинаковый материал дерева/металла на входе и выходе даёт
бонус толщины ×2. Выходные следы реплицируются; урон может пройти через игрока.

Нож: ЛКМ 20 при первом взмахе, 15 при продолжении серии; ПКМ 65.
Только ПКМ получает ×3 в спину: **195 до брони, 165 в кевлар**.
Проверка спины — горизонтальный LOS от атакующего к жертве и её forward,
скалярное произведение строго `> .8`. ArmorRatio ножа — 1.7.
Дальности 48/32 units; сначала линия, при промахе sweep hull ±16 по горизонтали,
±18 по вертикали. Это generic damage, без бонуса за «голову ножом».
Урон разрешается на ближайшем безопасном physics tick; smack-звук и след
ждут .1/.2 s. Паузы ЛКМ: .5/.5 при попадании, .4/.5 при промахе;
ПКМ: 1.1 при попадании, 1.0 при промахе. Inspect остаётся косметическим.

## Импакт

CSS намеренно **не прикладывает физическую силу к живому игроку**.
Урон не добавляет отбрасывание в `Velocity`.

Вместо этого задаётся velocity modifier: .5 для малого flinch; .65 для
винтовки/снайперки по стоящей жертве, кроме ног, если полная скорость <300 u/s.
При большой скорости большой flinch сохраняет текущий modifier. Ограничение
скорости действует на земле; восстановление на земле — `dt / 3` до 1.

Без брони попадание в грудь/живот задаёт pitch `max(-4, -.1 * damage)`;
голова без шлема — `max(-12, -.5 * headDamage)` и случайный roll ±9.
Руки/ноги и generic-удар ножа не добавляют aim punch. Броня/шлем подавляют
соответствующую сбивку. Сбивка влияет и на камеру, и на направление следующей
пули. Возврат использует CSS `length -= (10 + length * .5) * dt`.
Приземление от 350 u/s добавляет Source roll `fallSpeed * .013`.

Урон проигрывает оригинальные Flesh.BulletImpact, DamageKevlar,
DamageHelmet, DamageHeadShot, FallDamage, Death/DeathHeadShot, а нож —
Hit/Stab/HitWall. Звук HP-события не пересылается вторично через клиентский
канал оружейного аудио. Кровь и искры шлема создаются подтверждённым событием
урона, включая событие для стрелявшего клиента.

HE с уроном в HP >=30 вызывает оглушение: задержка .3 s, эффект 4.5 s,
вход .1 s, выход 1.5 s; пресеты 137/138/139 используют 4000/2000/1000 Hz
low-pass и тон 3000 Hz с уровнем .01/.02/.03. `SourceDamageHearing`
воспроизводит расписание; фильтр и генератор освобождаются при выходе.

## Падение и HE

Падение: `max(0, speed - 580) * (100 / 520) * 1.25`.
Скорость приходит до первого полушага гравитации. Вода, noclip и spectator
отменяют игровой урон; телепорт очищает старую скорость падения.
Скорость опускающейся опоры вычитается из удара, `source_floating` даёт
допуск 200 u/s. Плавучесть автоматически эта метаинформация не моделирует.

HE: базовый урон 100, радиус 350, Gaussian sigma `350 / 3`.
Сохраняются выборка экспозиции и плотности укрытий, описанные в коде
GrenadeProjectile: глаз/грудь 40%, голова 20%, ноги 20%, стороны по 10%.
Сплошной мир закрывает выборку, физические объекты ослабляют по плотности,
другой игрок оставляет 75%; вода отделяет воздушный/подводный взрыв.

По умолчанию HE использует оригинальный WeaponArmorRatio 1.475, включая
урон самому бросившему. `sv_legacy_grenade_damage 1` воспроизводит старую
особенность CCSPlayer: берёт armor ratio **текущего оружия бросившего**.
Для world-взрыва без attacker остаётся ratio 1.0 (коэффициент HP .5).

Friendly fire по умолчанию включён для текущего режима с одной командой.
Пули и нож союзника
получают ×.35 до обработки брони; HE — полный урон. Своя HE вредит всегда.

## Консоль

| Команда | Назначение |
| --- | --- |
| `sv_falldamage 0` / `1` | Выключить/включить только урон падения; **расширение Contrapoint** |
| `mp_friendlyfire 0` / `1` | Урон союзникам; по умолчанию 1 в Contrapoint |
| `sv_legacy_grenade_damage 0` / `1` | Современный/старый выбор armor ratio HE |
| `sv_cheats 1; god` | Переключить неуязвимость; также `god 0` / `1` |
| `sv_cheats 1; buddha` | Оставлять минимум 1 HP; также `buddha 0` / `1` |
| `sv_cheats 1; hurtme 20` | Нанести себе generic-урон; без числа 10 |
| `sv_cheats 1; player_debug_print_damage 1` | Печатать тип, hitgroup, HP/armor damage |
| `violence_hblood 0` / `1` | Локально выключить/включить кровь |
| `cl_ragdoll_physics_enable 0` / `1` | Физика новых рэгдоллов |
| `cl_disablefreezecam 0` / `1` | Локальный выключатель камеры убийцы |
| `sv_disablefreezecam 0` / `1` | Серверный выключатель камеры убийцы |
| `spec_freeze_time 5` | Длительность стоп-кадра CSS |
| `spec_freeze_traveltime 0.7` | Длительность подлёта камеры CSS |
| `sv_cheats 1; spec_freeze_distance_min 80` | Минимальная дистанция камеры, Source units |
| `sv_cheats 1; spec_freeze_distance_max 90` | Максимальная дистанция камеры, Source units |
| `sv_autorespawn 0` / `1` | Автоматический респавн; расширение Contrapoint, включён |
| `sv_respawn_delay 6.5` | Пауза до автоматического респавна; расширение Contrapoint |
| `respawn` | Ручной респавн; также HOME, после смерти SPACE / ENTER / ЛКМ |
| `jpeg` / `screenshot` | Снимок в `user://screenshots`; по умолчанию F5 = `jpeg` |

Автодополнение, `help`, `find`, `toggle` используют существующий каталог
консоли. В LAN игровые cvar и cheat-команды изменяет хост. Значения правил
приходят клиентам при подключении и изменении; после отключения возвращаются
их локальные значения. `sv_cheats 0` очищает god/buddha.

Не выдаём `sv_falldamage` за команду CSS: её CCSGameRules::FlPlayerFallDamage
не проверяет отдельный выключатель. Общий Source/HL2MP `mp_falldamage`
выбирает фиксированный/прогрессивный расчёт и не служит выключателем CSS.

## Рэгдолл и экран смерти

`import_css_ragdolls.py` извлекает из четырёх оригинальных PHY по 16 выпуклых
тел, массы, damping и угловые ограничения. `SourceRagdoll` переносит текущую
позу и скорость игрока на `PhysicalBone3D`, прикладывает смертельный импульс
к месту попадания (для головы — Head1), с множителем Event_Killed ×2.
Столкновения с миром воспроизводят оригинальные `Flesh.ImpactSoft/Hard`.
Оружие в руках удаляется **до** копирования скелета: ни на живом скрытом теле,
ни на рэгдолле его не остаётся. На респавне оружие появляется снова.
Рэгдоллы живут 30 секунд, максимум 12 одновременно.

Камера трупа длится .8 секунды, затем подлетает за .7 секунды на дистанцию
80–90 Source units и замирает на 5 секунд. Это настройки `CSTRIKE_DLL`, а не
общей ветки Source. Панель появляется при входе в freezecam. Для текущего
песочного режима после 6.5 секунды происходит респавн, раньше можно вручную
после первых .8 секунды. Без убийцы / с отключённой freezecam остаётся камера трупа.

`import_css_death_ui.py` переносит `resource/ui/FreezePanel_Basic.res`, определения
FreezeSmall/Medium/Large из ClientScheme, русскую локализацию, VTF аватары и
свечение, `UI/freeze_cam.wav`. Используется указанная в CSS Windows Verdana Bold
с пересчётом высоты GDI. `CssFreezePanel` читает импортированную раскладку;
граница и шкала здоровья повторяют алгоритм исходных VGUI-контролов.
Своих кнопок, таймеров и текста причины смерти у панели нет. Обычный kill
скрывает значок domination; система nemesis/revenge и Steam-аватары ещё не реализованы.
Исходные res/VMT и ссылки на реализацию сохранены в
`tools/source_import/references/death`, SHA — `assets/ui/css/death/provenance.json`.

В LAN хост надёжно отправляет позу, скорость, точку, силу и hitgroup смерти,
а каждый клиент создаёт косметическую физику трупа. Респавн хоста обновляет
всех клиентов и увеличивает teleport revision, чтобы старый пакет позы не
вернул игрока к трупу. Правила камеры и автореспавна приходят от хоста.

## Проверки и границы

`damage_checks.tscn` — 52 проверки формул, зон, брони, FF, команд, воды,
реальных падений и взрывных укрытий. `weapon_damage_checks.tscn` — профили
шести оружий, глушители, четыре модели, голова/тело, реальное пробитие,
нож спереди/сзади, эффекты и жизненный цикл оглушения.
`combat_checks.tscn` проверяет коллизии, следы, тайминги и физические props.
`death_checks.tscn` проверяет реальные PHY-тела, инерцию, импульс в голову,
удаление оружия, звуки столкновений, оригинальную панель и респавн.
`death_preview.tscn` сохраняет кадры полёта тела и freezecam в `.godot/death_*.png`.
`tools/run_lan_checks.ps1` запускает три настоящих ENet-процесса, включая
взаимный вражеский огонь, броню, backstab, смерть, cvar, респавн и late join.
Все проверки используют Mono Godot и `--audio-driver Dummy`.
`tools/source_import/preview_damage.gd` сохраняет визуальную проверку в
`.godot/damage_preview.png`.

Это перенос правил CSS поверх существующей Godot-игры. Jolt-коллизии,
интерполяция/смешивание анимаций, частицы и звуковой микшер не являются
оригинальными подсистемами Source. Кровь использует оригинальные текстуры,
но Godot sprites вместо Source emitter, без полного TraceBleed/decal и
коллизий капель; DSP представлен low-pass/тоном без всей сети Source DFR.
Knife hull не повторяет покомпонентно Source FindHullIntersection для BSP.
Пробитие использует доступные метаданные поверхностей; CONTENTS_GRATE без
соответствующего surface и особые несовпадающие BSP-материалы могут отличаться.
Рэгдолл использует исходные PHY-данные, но решатель Jolt вместо VPhysics;
поэтому траектории и звуки контактов не будут побитово одинаковыми с CSS.
LAN по-прежнему доверяет перемещению/aim владельца, без rewind/lag compensation
и полной серверной симуляции команд. Существующая CSSO отдача/точность AK/M4
не заменялась. Эти различия не позволяют заявлять полное визуальное и сетевое 1:1.
